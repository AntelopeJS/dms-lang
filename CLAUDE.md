# @antelopejs/dms-lang

> AntelopeJS DMS module providing language management over i18n workspaces (own/modules/added): an overview (coverage KPIs, ranked languages, namespace heatmap), a translation matrix with a key drawer, a per-language translation queue, a workspaces page and workspace settings. Every page shows the selected workspace in a scope bar and keeps it in the URL (`?workspace=`). Design rationale: [docs/v2-redesign-grill.md](./docs/v2-redesign-grill.md).

See [AGENTS.md](./AGENTS.md) for code conventions and guidelines.
